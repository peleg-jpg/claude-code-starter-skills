# ערכת סקילים למתחילים בקלוד קוד

13 סקילים שאני משתמש בהם כל יום, אחרי ניקוי של כל מה שאישי. התקנה אחת וזהו.

## התקנה (דקה)

פותחים טרמינל ומדביקים:

</div>

```bash
git clone https://github.com/peleg-jpg/claude-code-starter-skills.git
cd claude-code-starter-skills
./install.sh
```

<div dir="rtl">

אחרי זה סוגרים ופותחים מחדש את קלוד קוד. אם כבר יש לך סקיל עם אותו שם, הסקריפט שומר גיבוי לפני שהוא מחליף.

## מה מקבלים

### חמשת הבסיסיים (תתחיל מפה)

| סקיל | מה הוא עושה | איך מפעילים |
|---|---|---|
| superpowers | מלמד את קלוד לתכנן לפני שהוא בונה, לדבג בצורה מסודרת ולבדוק לפני שהוא אומר "סיימתי" | עובד לבד |
| grill-me | קלוד שואל אותך שאלה אחרי שאלה עד שהרעיון ברור, לפני שכותבים שורת קוד | <span style="direction:ltr;unicode-bidi:embed">grill me</span> |
| skill-creator | בונה לך סקילים משלך כשאתה שם לב שאתה חוזר על אותה משימה | <span style="direction:ltr;unicode-bidi:embed">/skill-creator</span> |
| claude-md-management | שומר על קובץ ה־CLAUDE.md שלך קצר ומעודכן | <span style="direction:ltr;unicode-bidi:embed">/revise-claude-md</span> |
| caveman | קלוד עונה קצר ובלי חפירות, חוסך הרבה טוקנים | <span style="direction:ltr;unicode-bidi:embed">/caveman</span> |
